📋 MODELOS IMPLEMENTADOS
═══════════════════════════════════════════════════════════════════

1. Role (apps/core/models.py)
   Fields: name, description, created_at, updated_at
   Choices: client, manager, operator, admin

2. UserProfile (apps/core/models.py)
   Links: ForeignKey User, ForeignKey Role
   Fields: company, phone, status, created_at, updated_at
   Status: active, inactive, suspended

3. Audit (apps/core/models.py)
   Fields: user, model_name, object_id, action, details, ip_address, timestamp
   Logging de todas las acciones del sistema

4. Document (apps/documents/models.py)
   Fields: FileField, type, owner, title, description, file_size, is_public, uploaded_at
   Types: original, processed, evidence, report

5. Task (apps/tasks/models.py)
   Fields: title, description, status, priority, created_by, assigned_to, dates
   Status: pending, assigned, in_progress, review, completed, rejected
   Priority: low, medium, high, urgent

🚀 INSTALACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════════

OPCIÓN 1 - Automática:
  cd /home/rolando/Documentos/Kyros
  ./setup_complete.sh

OPCIÓN 2 - Manual:
  cd /home/rolando/Documentos/Kyros
  source venv/bin/activate
  pip install -r requirements.txt
  cd backend
  python manage.py migrate
  python manage.py createsuperuser
  python manage.py runserver

Luego accede a:
  - http://localhost:8000/         (Landing page)
  - http://localhost:8000/admin/   (Admin panel)
  - http://localhost:8000/api/     (API endpoints)
